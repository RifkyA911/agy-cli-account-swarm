🩺 Built-In Diagnostic Engine

Profile Doctor & Diagnostic Engine

Automated 5-checkpoint sandbox health verification, process lock mitigation, and self-healing engine.

1. Diagnostic Checkpoints

⚡
1. AGY CLI Binary & Version Check
Verifies that the Antigravity CLI executable is installed and reachable via system PATH or custom configured path, reporting the installed version string.
🔑
2. OAuth Token Validity & Expiry
Inspects the isolated antigravity-oauth-token, validates UTF-8 JSON without BOM, and parses JWT expiration claims to alert before credentials lapse.
🔒
3. Lingering Process & Presence Locks
Scans for orphaned presence/*.lock and SQLite journal locks left behind by abrupt terminal closures, preventing fatal startup lockouts.
🛡️
4. Workspace Anchor & Trust Status
Checks that the designated workspace folder exists, is writable, and is pre-registered in trusted_workspaces.json to bypass interactive security modals.
📊
5. /usage Schema Compatibility Probe
Executes zero-token agy -p "/usage" --output-format json to ensure local telemetry buckets (weekly and 5-hour limits) match upstream schema expectations.

2. One-Click Self-Healing Remediation

When Profile Doctor detects non-critical anomalies, it enables discrete 1-click self-healing operations directly on the account card:

Diagnostic Trigger Self-Healing Action Automated Resolution
Stale presence/*.lock files detected 🧹 Clear Stuck Lock(s) Safely removes abandoned lock files while verifying no active agy process is attached.
Untrusted workspace directory 🛡️ Register Workspace Trust Appends path to trusted_workspaces.json, enabling headless swarm execution.
UTF-8 BOM in OAuth token 🔄 Quick Sync Automatically strips \ufeff byte order mark and rewrites pure UTF-8 JSON.

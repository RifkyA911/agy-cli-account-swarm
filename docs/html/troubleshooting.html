Troubleshooting & Operational Diagnostics

Actionable fixes for common CLI initialization errors, process locks, and terminal anomalies.

Common Failure Modes & Verified Solutions

1. Token Unmarshal Error: invalid character '\ufeff'
Cause: Windows UTF-8 text writers injected a Byte Order Mark (BOM) into antigravity-oauth-token, which Go's JSON unmarshaler rejects.
Solution: Fixed automatically on startup in v0.9.7-beta+ via self-healing migration. Click 🔄 Quick Sync to restore valid BOM-free formatting.
2. Batch Syntax Crash: ]] was unexpected at this time
Cause: Windows cmd.exe syntax failure when profile titles containing parentheses (e.g. Default (Main Account)) are parsed in if (...) blocks.
Solution: Resolved via linear label branching (goto :cli_only). Click Edit Profile and save to regenerate your run-agy.cmd.
3. Lingering Presence Locks & Database Lockouts
Cause: Abrupt terminal closures leave orphaned presence/*.lock and SQLite journal locks.
Solution: Click 🧹 Clear Stuck Lock(s) on the account card or run scripts/clean-sandbox.ps1.
4. Automated Worker Freezes on Interactive Prompts
Cause: The Antigravity CLI pauses waiting for interactive confirmation to execute tools or write files.
Solution: Enable the --dangerously-skip-permissions toggle inside the Profile Edit Dialog.
5. Untrusted Workspace Directory Halts Execution
Cause: The workspace folder is not registered in the profile's trusted_workspaces.json.
Solution: Run Profile Doctor on the account card and click Register Workspace Trust.

Reference Manual

Database Schemas & Configuration Reference

Complete DDL/DML specifications, JSON layout, and configuration parameters.

1. SQLite Database Schema (conversation_summaries.db)

Located at ~/.gemini/antigravity-cli/conversation_summaries.db inside each profile directory: 

-- SQLite Schema: DDL
CREATE TABLE IF NOT EXISTS conversation_summaries (
    conversation_id TEXT PRIMARY KEY,
    workspace_path  TEXT NOT NULL,
    summary_text    TEXT,
    model_name      TEXT NOT NULL DEFAULT 'gemini-3.8-flash',
    total_tokens    INTEGER DEFAULT 0,
    created_at_ms   INTEGER NOT NULL,
    updated_at_ms   INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS annotations (
    annotation_id   TEXT PRIMARY KEY,
    conversation_id TEXT NOT NULL,
    snippet_content TEXT,
    created_at_ms   INTEGER NOT NULL,
    FOREIGN KEY(conversation_id) REFERENCES conversation_summaries(conversation_id)
);

2. JSON Schema: settings.json

The orchestrator persists user choices in %APPDATA%\AgyAccountSwarm\settings.json: 

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "AppSettings",
  "type": "object",
  "properties": {
    "PreferredTerminal": { "type": "string", "enum": ["WindowsTerminal", "PowerShell", "CommandPrompt"] },
    "SwarmMode": { "type": "string", "enum": ["SplitPanes", "SeparateTabs", "SeparateWindows"] },
    "Theme": { "type": "string", "enum": ["Dark", "Light"] },
    "Language": { "type": "string", "enum": ["en", "id"] },
    "PreferredChartMode": { "type": "string", "enum": ["Bar", "Line", "Area"] },
    "AutoSyncInterval": { "type": "string", "enum": ["Manual", "1 Minute", "5 Minutes", "15 Minutes", "30 Minutes"] },
    "SoundEnabled": { "type": "boolean" },
    "CloseToTray": { "type": "boolean" },
    "MinimizeToTray": { "type": "boolean" }
  }
}

3. Configuration Keys & Defaults

Key Type Default Description
Language string "en" Active UI language ("en" for English, "id" for Bahasa Indonesia).
PreferredChartMode string "Bar" Coordinate rendering style for vector telemetry graphs ("Bar", "Line", "Area").
AutoSyncInterval string "5 Minutes" Periodic timer interval for refreshing telemetry and checking MCP tool availability.
SoundEnabled boolean true Enables synthesized acoustic feedback for transactions, launches, and quota alarms.

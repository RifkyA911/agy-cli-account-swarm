Model Context Protocol (MCP) Guide

Extending Antigravity CLI agents with structured tool servers and schema reflection.

1. MCP Architecture Overview

The Model Context Protocol (MCP) is an open specification enabling AI models to interact with external tools, APIs, and file systems over standard input/output (stdio) using JSON-RPC 2.0.

2. Discovered Local Servers (Example: Context7)

Agy Account Swarm scans %USERPROFILE%\.gemini\antigravity-cli\mcp\ for tool schemas:

Tool Name Parameters Description
query-docs libraryId (string), query (string) Queries indexed documentation libraries for code patterns and API references.
resolve-library-id libraryName (string) Resolves package or library names to their canonical Context7 library IDs.

2. Windows Installation

Option A: GUI Setup Installer

  1. Download Agy-CLI-Account-Swarm-Setup-v0.9.13-beta.exe from GitHub Releases.
  2. Launch the installer and follow the setup wizard.
  3. The application installs per-user into %LOCALAPPDATA%\Programs\Agy CLI Account Swarm without requiring UAC Administrator elevation.

Option B: Standalone Portable ZIP

  1. Extract the ZIP archive to your desired directory.
  2. Run AgyCliAccountSwarmGUI.exe.

3. Linux Installation (Wayland & X11)

tar -xzf Agy-CLI-Account-Swarm-v0.9.13-beta-linux-x64.tar.gz
cd agy-cli-account-swarm-v0.9.13-beta-linux-x64
bash install.sh

The installer copies binaries to ~/.local/share/agy-cli-account-swarm, creates terminal wrapper ~/.local/bin/agy-cli-account-swarm, and registers a .desktop entry in your desktop app drawer.

4. macOS Installation (Apple Silicon & Intel)

tar -xzf Agy-CLI-Account-Swarm-v0.9.13-beta-macos-arm64.tar.gz
cd agy-cli-account-swarm-v0.9.13-beta-macos-arm64
bash install.sh

The installer copies Agy CLI Account Swarm.app to /Applications, clears macOS Gatekeeper quarantine attributes (xattr -cr), and symlinks the launch command.

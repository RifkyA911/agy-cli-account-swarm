💬 Context Transfer Engine

Cross-Account Chat Migration Guide

Transfer conversation turns, agent reasoning trajectories, and task state between profiles with 100% credential segregation.

1. Security & Credential Isolation Guarantees

The Chat Migration pipeline (ConversationTransferService) was engineered specifically to transfer developer context without violating Google account boundaries:

Component Transferred? Safety Standard
history.jsonl (Prompt turns) ✅ Yes Filtered strictly by target conversation ID and cleanly appended.
brain/{convId}/ (Transcripts & Trajectories) ✅ Yes Clones agent thought steps, tool outputs, and generated artifacts.
conversations/{convId}.db (SQLite Session DB) ✅ Yes Preserves turn numbers, tokens, and model timestamps.
antigravity-oauth-token (Google OAuth Token) ❌ NEVER Strictly locked & ignored. The target account authenticates exclusively using its own Google credentials.
google_accounts.json (Active Identity) ❌ NEVER Untouched. The target account maintains its own Google identity.

2. Step-by-Step Migration Flow

1. On the Account Card needing past context, click 📥 Import Chat.

2. Select the Source Account and choose the desired conversation from the searchable list.

3. Confirm the Target Account destination and click 🚀 Transfer Conversation.

4. In the target account, click Launch agy with --conversation <id> to immediately pick up the discussion exactly where you left off.

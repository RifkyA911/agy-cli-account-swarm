🧪 EXPERIMENTAL ARCHITECTURE SPECIFICATION

Fleet Prompt Dispatcher & Git Worktree Orchestrator

Automated single-prompt distribution across multiple autonomous Google Antigravity CLI workers with Git Worktree isolation, graceful fallbacks, and resource sentinels.

1. Executive Summary & Architecture

The Fleet Prompt Dispatcher solves the fundamental problem of multi-agent CLI coordination: eliminating the need for the user to manually type commands into 4 separate terminal windows, while simultaneously eliminating repository lock contention via git worktree.

⚡ 1-Click Objective Dispatch

User writes 1 task in GUI. Dispatcher synthesizes role contexts (Backend, API, Test, Docs) and automatically launches N workers with tailored prompts.

🌿 Zero Lock Collisions

Each worker receives an isolated physical working tree linked to a unified .git store. Staging and commits run concurrently with zero index.lock blocks.

2. Robustness Matrix: Handling Fallback, Errors, Warnings, and OOR

2.1 Fallback Handling (Graceful Degradation)

Fallback Scenario Detection Mechanism Automated Graceful Recovery
Non-Git Workspace git rev-parse --is-inside-work-tree fails or returns non-zero. Automatically falls back to Dedicated Sandbox Workspace (~/.gemini-profiles/{id}/workspace) without throwing errors. Displays informative UI warning badge.
Terminal Host Unavailable Requested terminal (e.g. wt.exe) is not installed. Cascading fallback: wt.exe → powershell.exe → cmd.exe on Windows; $TERMINAL → x-terminal-emulator → ptyxis → gnome-terminal → konsole → bash on Linux; osascript → Terminal.app on macOS.
Dirty Working Tree git status --porcelain detects uncommitted edits in working directory. Proactive choice: automated temporary git stash before worktree provisioning, or branching directly from latest commit HEAD without risking uncommitted files.
Exhausted Worker Quota Live telemetry detects 5-hour limit < 5% or quota status is exhausted. Excludes exhausted worker from dispatch batch, alerts user, and recommends the fleet worker with the highest remaining capacity.

2.2 Error Handling & Auto-Recovery

Error Condition Root Cause System Auto-Resolution
Stale Worktree Lock Previous crash left .git/worktrees/<id>/locked or index.lock. Executes git worktree prune and surgical unlock on the targeted worktree before aborting.
Branch Name Collision Branch swarm/worker-1 already exists from a prior run. Uses microsecond timestamped branch naming: swarm/{worker}_{yyyyMMdd_HHmmss}, guaranteeing uniqueness.
Subprocess Fatal Crash agy CLI crashes due to invalid flag, network cutoff, or auth failure. Process supervisor catches exit code and stderr, logs to ring buffer, kills lingering child processes, and flags UI status as failed.
Reconciliation Merge Conflict Two workers edited the same lines in the same file. System aborts automated merge safely without corrupting main, highlights conflicting files, and provides manual 3-way resolution options.

2.3 Warning Sentinels (Proactive Alerts)

Warning Signal Threshold UI Action & Recommendation
Low 5-Hour Limit Worker remaining 5h fraction between 5% and 20%. Yellow warning badge: ⚠️ Low Quota (X% left). User can proceed or swap worker.
Weekly Tier Ceiling Worker weekly quota remaining < 10%. Alert banner explaining weekly tier quota limits and reset countdown.
Massive Repository Checkout Target repo > 500 MB or > 50,000 files. Notification indicating worktree checkout may take 3-5 seconds on mechanical or network drives.

2.4 Out-of-Resources (OOR) Protection Protocol

Critical Safeguard: Hardware Starvation Prevention

Launching 4+ AI agent sessions simultaneously can saturate CPU, RAM, and disk storage if not guarded.

Hardware Resource Critical Limit Active Protection Mechanism
Disk Storage Free drive space < 2.0 GB. Pre-flight Block: Aborts worktree creation before disk write. Notifies user to free disk space.
System Memory (RAM) Free RAM < 1.5 GB or usage > 90%. Concurrency Throttling: Reduces concurrent active workers from 4 to 2, queuing remaining tasks.
CPU Load Spikes N processes starting at the exact same millisecond. Staggered Launch: Enforces a 600ms stagger delay between worker process invocations.
Orphan / Zombie Processes User clicks "Stop Swarm" while child tasks are compiling. Process Tree Termination: Calls proc.Kill(entireProcessTree: true) to guarantee all spawned sub-processes are wiped.

Antigravity CLI (agy) Command Reference

Complete specification of CLI invocations, telemetry inspection commands, and launcher scripts.

1. Key Command Invocations

Command Syntax Turns Tokens Description & Use Case
agy 1+ Variable Interactive default prompt session inside isolated workspace.
agy -p "/usage" --output-format json 0 0 Extracts 5-hour and weekly capacity metrics without polluting chat history.
agy -p "/context" --output-format json 0 0 Retrieves model context window headroom and cached token usage.
agy --dangerously-skip-permissions 1+ Variable Bypasses interactive tool, file write, and bash execution confirmation modals.
agy --conversation <id> 1+ Variable Resumes a specific past conversation transcript from the sandbox's brain store.
agy -p "/continue" 1+ Variable Seamlessly resumes the most recent conversation session in the workspace.

2. Environment Variable Sandboxing Contract

Each worker CLI instance receives a decoupled environment to guarantee that secondary accounts never inherit the host keyring or clash over locks:

USERPROFILE="~/.gemini-profiles/{id}"
HOME="~/.gemini-profiles/{id}"
ANTIGRAVITY_APP_DATA_DIR="~/.gemini-profiles/{id}/.gemini/antigravity-cli"
SSH_CONNECTION=1
SSH_CLIENT=1

Note: For the Default (Main Account), SSH_CONNECTION and SSH_CLIENT are explicitly cleared to allow natural Windows Credential Manager integration.

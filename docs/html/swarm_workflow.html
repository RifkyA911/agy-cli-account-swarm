Swarm Execution & Window Tiling Workflow

Lifecycle of parallel agent initialization, terminal multiplexing, and process cleanup.

2. Terminal Layout Modes

Mode Terminal Target Execution Command Pattern Best Suited For
Split Panes Windows Terminal (wt.exe) wt.exe -p "PowerShell" -d "..." ; split-pane -H -d "..." ; split-pane -V ... Single monitor, high-density matrix monitoring.
Separate Tabs Windows Terminal (wt.exe) wt.exe -p "PowerShell" -d "..." ; new-tab -p "PowerShell" -d "..." Full screen per worker with tab switching.
Separate Windows PowerShell / Windows Terminal Independent Process.Start invocations per profile. Multi-monitor setups or detached background runners.

3. Process Signal Handling & Safe Exit

When closing a session, the child process sends a graceful cancellation to the language server. Because each profile runs in its own process tree, closing or crashing one worker never impacts the active state of another worker.

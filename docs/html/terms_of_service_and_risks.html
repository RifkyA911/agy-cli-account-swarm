Terms of Service, Policies & Risk Advisory

Operational architecture, local sandboxing boundaries, and policy compliance for Google Antigravity CLI (agy) orchestration.

⚠️ Disclaimer of Affiliation: Agy CLI Account Swarm is an independent third-party open-source project and is NOT sponsored, maintained, or endorsed by Google LLC or Alphabet Inc.
🖥️ GUI Desktop Only Scope: This repository operates strictly as a graphical desktop application. A standalone headless CLI orchestration interface will be published in a separate dedicated project named agy-swarm.

1. 100% Local File Sandboxing Architecture

Agy CLI Account Swarm isolates accounts entirely through native operating system mechanisms:

  • Isolated Profiles: Stored in ~/.gemini-profiles/{id}/ with independent environment configurations.
  • No Cloud Token Interception: Tokens (oauth_credentials.json) remain locally secured. The app never uploads credentials to any remote server.
  • Zero Synthetic Data: Telemetry is parsed dynamically from local history.jsonl logs and authenticated agy -p "/usage" results with zero dummy data.

2. Chat History Migration Compliance

The Import Chat feature executes strictly on your local disk:

  • It copies conversation turn transcripts from history.jsonl, session databases from conversations/, and artifacts from brain/ between local sandboxes.
  • OAuth tokens are never copied or merged. Each profile preserves its unique authenticated Google identity.

3. Rate Limits & Fair Use Policy

Google Antigravity services enforce capacity limits:

  • Weekly Limit: Based on subscription tier (Basic: 100, Plus: 300, Pro: 1,000, Ultra: 2,500 prompts/day).
  • 5-Hour Rolling Limit: Protects aggregate capacity across global users.
  • Users must avoid abusive parallel automation that could trigger IP rate-limiting or anti-abuse throttling.

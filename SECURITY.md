# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| v1.3.x  | :white_check_mark: |
| < v1.3  | :x:                |

## Reporting a Vulnerability
If you discover any security vulnerabilities or credential leakage risks within the swarm sandboxing architecture:
1. Please do **NOT** open a public issue.
2. Contact the maintainer directly through GitHub private security advisories or via `https://github.com/RifkyA911`.
3. Provide detailed steps to reproduce the issue along with environment specifics.
4. We will evaluate and patch the issue promptly.
